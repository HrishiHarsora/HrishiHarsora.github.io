# hrishi's blog

A minimal personal blog in the style of [Bear Blog](https://bearblog.dev)-type sites:
a title-and-nav header, a home page with an intro, a reverse-chronological blog,
About and Reading pages, automatic light/dark theme, and an RSS feed.

Everything is generated by a single dependency-free Python script.

## Quick start

```
python build.py serve
```

then open http://127.0.0.1:8000. Plain `python build.py` just builds into `site/`.

## Writing a post

Create `content/posts/YYYY-MM-DD-your-slug.md`:

```
---
title: Your post title
date: 2026-07-02
---

Post body in markdown.
```

Rebuild, and it appears on the blog index and the RSS feed.
Supported markdown: headings, paragraphs, bold/italic, links, inline code,
fenced code blocks, bullet and numbered lists, blockquotes, horizontal rules.

## Editing pages

- `content/home.md` — intro text on the home page
- `content/about.md` — the About page
- `content/reading.md` — the Reading page

## Making it yours

Edit the `SITE` dict at the top of `build.py`:

- `title`, `tagline`, `author`, `email`
- `github_url` — the nav "Code" link (currently a placeholder)
- `cv_url` — the nav "CV" link (currently a placeholder)
- `base_url` — your real domain, used in `feed.xml` (set before deploying)

## Deploying

The `site/` folder is plain static files. Push it to GitHub Pages, Netlify,
Cloudflare Pages, or any static host. On Netlify/Cloudflare, set the build
command to `python build.py` and the publish directory to `site`.
